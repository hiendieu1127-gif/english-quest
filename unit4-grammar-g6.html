Unit 4: My Neighbourhood

Grammar

So sánh hơn (Comparative adjectives). Đọc lý thuyết rồi làm lần lượt Bài 3, Bài 4, Bài 5 nhé.

📘 Lý thuyết — bấm để ẩn / hiện

So sánh hơn (Comparative adjectives)

Cách dùng: dùng để so sánh hai người hoặc hai vật.

Tính từ ngắn (1 âm tiết, hoặc 2 âm tiết tận cùng là -y, -er, -le, -ow, -et):

S1 + be + adj-er + than + S2 be là động từ tobe ( is, am, are )

EX: Tom is taller than Mary.   (tall → taller)

EX: Tâm is ....smaller......... ( small) than Long.

Tính từ dài (2 âm tiết trở lên, trừ các trường hợp trên):

S1 + be + more + adj dài + than + S2 be là động từ tobe ( is, am, are )

EX: A house in a city is more expensive than a house in the countryside.

Ex: Ha Noi is ..more modern ( modern ) than my hometown.

Examples — Thêm ví dụ về so sánh hơn

Tính từ ngắn (1 âm tiết) → adj + -er

tall → tallersmall → smallercheap → cheaperold → olderfast → faster

Ex: My house is smaller than your house.

Tính từ 2 âm tiết tận cùng là -y, -er, -le, -ow, -et → tính từ ngắn

-y: happy → happier, busy → busier, noisy → noisier-er: clever → cleverer
-le: simple → simpler, gentle → gentler-ow: narrow → narrower-et: quiet → quieter

Ex: This street is narrower and quieter than that street.

Tính từ dài (2 âm tiết trở lên, trừ các trường hợp trên) → more + adj

beautiful → more beautifulexpensive → more expensivemodern → more modern

Ex: Ha Noi is more modern than my hometown.

Lưu ý

  1. Tính từ kết thúc bằng -e → thêm -r:   nice → nicer,  large → larger
  2. Phụ âm – nguyên âm ( u, e, o, a, i ) – phụ âm → gấp đôi phụ âm cuối:   big → bigger,  hot → hotter
  3. Tính từ 2 âm tiết kết thúc bằng -y → bỏ y thêm -ier:   noisy → noisier,  busy → busier
  4. Bất quy tắc:   good → better,   bad → worse,   far → farther / further
3. Complete the sentences with the correct comparative form of the adjectives in the box — hoàn thành câu với dạng so sánh hơn của các tính từ trong khung.
4. Complete the sentences with the phrases in the box to make comparisons — chọn cụm từ trong khung để hoàn thành câu so sánh.
5. Write sentences, using the comparative form of the adjectives — viết câu, dùng dạng so sánh hơn của tính từ.
Example: Son / tall / Hung. → Son is taller than Hung.
